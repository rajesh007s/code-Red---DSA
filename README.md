## 📂 Recommended Solution File Naming

Organize your problem solution files within each topic folder using consistent naming:

```
<topic-folder>/
├── README.md               <-- Topic tracker & notes
├── 0001-two-sum.py         <-- (or .cpp / .java / .js / .ts)
├── 0015-3sum.py
└── notes.md                <-- Optional detailed problem breakdown
```

## 🔁 Spaced Repetition Revision Strategy

1. **Day 1:** Understand the intuition, write the solution from scratch without looking at answers.
2. **Day 3:** Re-solve without looking at your previous code.
3. **Day 7:** Re-attempt and explain the intuition out loud or write notes on edge cases.
4. **Day 30:** Quick speed-run implementation to ensure long-term retention.
