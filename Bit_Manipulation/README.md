## 📌 Core Concepts & Patterns

- Bitwise operators: &, |, ^, ~, <<, >>
- XOR properties: x ^ x = 0, x ^ 0 = x
- Brian Kernighan's Algorithm (n & (n - 1)) to count set bits
- Bitmasking for subset generation and state compression in DP
